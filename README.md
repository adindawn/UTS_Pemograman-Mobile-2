# Deskripsi 

  MemoAese adalah aplikasi pencatatan digital yang memudahkan pengguna dalam membuat, menyimpan, dan mengelola catatan secara praktis. Aplikasi ini memiliki antarmuka sederhana dan mudah digunakan, sehingga membantu meningkatkan produktivitas sehari-hari. 

  Aplikasi MemoAese dilengkapi dengan fitur daftar tugas (to-do-list), pencarian catatan. memoaese membantu pengguna mencatat ide, serta membantu pengguna mencatat tugas dan mengingat deadline dengan lebih terorganisir.
